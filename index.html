Project 1 5 marks Lectures 1–4

Profile Card

A one-screen app that shows a card about you, using only MaterialApp, Scaffold, AppBar, Center, Container and Text.

  • A new project called profile_card, with the DEBUG banner hidden
  • An AppBar with your name as the title and your own colors
  • A centered Container: fixed width, padding, color and rounded corners
  • Inside: your name, major, university and one line about you, styled and centered
  • Runs with no errors; code formatted with Shift + Alt + F

Project 2 8 marks Lectures 5–8

Login Page

A complete login screen with your own design. It must look good on a small phone and keep working when the keyboard is open.

  • A new project called login_page; LoginPage is its own StatelessWidget
  • SafeArea + SingleChildScrollView + Padding + Column
  • A logo from your assets folder (Image.asset), a title and a subtitle
  • Email field (icon, email keyboard) and password field (lock icon, hidden text)
  • "Forgot password?" on the right, a full-width Login button that shows a SnackBar
  • A "Don't have an account? Sign up" row, and no overflow with the keyboard open

Logo from assets, title and subtitle1

⭐ Want to impress? A tappable logo (GestureDetector), an AlertDialog for "Forgot password?", or a "Remember me" row.

Submit

How to submit on GitHub

The same three steps for every project.

Create a private repo

  1. Sign in at github.com
  2. Click + → New repository
  3. Name it like the project, choose Private

Push your project

In a terminal inside your project folder:

git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin <your repo URL>
git push -u origin main

Invite the instructor

  1. Repo → Settings → Collaborators
  2. Add people → Monther-bug
  3. Send the repo link in the class group
