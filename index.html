Profile Card

A one-screen app that shows a card about you, using only MaterialApp, Scaffold, AppBar, Center, Container and Text.

Submit

How to submit on GitHub

The same three steps for every project.

Create a private repo

  1. Sign in at github.com
  2. Click + → New repository
  3. Name it like the project, choose Private

Push your project

In a terminal inside your project folder:

$ git init
$ git add .
$ git commit -m "first version"
$ git branch -M main
$ git remote add origin <repo URL>
$ git push -u origin main

Invite the instructor

  1. Repo → Settings → Collaborators
  2. Add people → Monther-bug
  3. Send the repo link in the class group
