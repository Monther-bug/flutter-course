# Flutter Course website

Live: https://monther-bug.github.io/flutter-course/

| File | What it does |
|---|---|
| `index.html` | Home page, built like a slide presentation |
| `lecture.html` | One template for every lecture page (`lecture.html?n=1` … `?n=8`) |
| `js/data.js` | **All the content**: lectures, code, videos, practice, grades. Edit this to add a lecture. |
| `js/ui.js` | Shared: icons, animations, code highlighting |
| `js/home.js` | Builds the home page from the data |
| `js/lecture.js` | Builds a lecture page from the data |
| `css/main.css` | All styles |
| `assets/` | Project example images |
